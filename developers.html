Tallinn Tastebuds

For developers

Tallinn Tastebuds API v1 · stable

Read the places on the map and the public lists from your own app or site. Free, no key, JSON, any origin.

The addresses

Everything is GET on https://tallinntastebuds.ee.

  • /api/v1/placesq words, type, max_price 1–4, near=lat,lng, radius in metres, ids=a,b,c, lang, limit up to 100, offset
  • /api/v1/places/{id}one place, with every photo and a Google Maps link
  • /api/v1/liststhe public lists: q, by a username, limit up to 50, offset
  • /api/v1/lists/{id}one public list, its places in its author's order
  • /api/v1/typesthe kinds of place, named in all eleven languages
  • /api/v1the version and these addresses, as JSON

An example

curl 'https://tallinntastebuds.ee/api/v1/places?type=bakery&limit=1'
{
  "version": 1,
  "total": 17, "offset": 0, "limit": 1, "next": 1,
  "places": [{
    "id": "bekker-pagariari",
    "name": "Bekker Pagariäri",
    "address": "…", "lat": 59.44, "lng": 24.73,
    "types": ["bakery"],
    "price": 2,
    "blurb": "…",
    "must_order": ["…"],
    "photo": "https://tallinntastebuds.ee/photos/…",
    "phone": null, "website": null,
    "reel": "https://www.instagram.com/reel/…",
    "reel_summary": null,
    "visited": "2025-06", "added": "2026-08-23",
    "url": "https://tallinntastebuds.ee/?spot=bekker-pagariari"
  }]
}

A search with near adds distance_m to each place and puts the nearest first. Otherwise the order is how well your words matched, then the name. It is never a ranking: being on the map is the verdict, and there are no scores.

Link every place to its url, and say the write-ups are Tallinn Tastebuds'. A list is its author's opinion, under their name, and not the map's. A list's place with approved: false is one its author added that is not on the map.

Errors

An error is { "version": 1, "error": { "code", "message" } }. Branch on the code: bad-request (400), not-found (404), closed (404, the place has closed), method-not-allowed (405) and unavailable (503, the lists cannot be read right now; the places still can).

Versions

Version 1 only ever gains fields. A change that would break your code — a field renamed, removed or retyped — ships as /api/v2, beside this one. Version 1 then keeps answering for at least six months, and every answer carries Deprecation and a Sunset header saying when it stops. Every answer carries API-Version: 1.

Answers are cached for five minutes. There is no key and no rate limit beyond Cloudflare's own; be kind to it.

Put the map on your site

<iframe src="https://tallinntastebuds.ee/embed?list=list-id"
  width="100%" height="480" style="border:0"
  title="Map of places in Tallinn" loading="lazy"></iframe>

Instead of list: type=bakery for one kind of place, ids=a,b,c for just those, or nothing for the whole map. Add lang=et for the language and style=green for the colours (red, green, blue or plum).

Not here

Opening hours, ratings and the city's other restaurants are Google's, and are not handed on. Nor are directions or address search, which come from other people's free services. And the addresses above write nothing: saving and lists are done on the site.

The site's own apps

The Tallinn Tastebuds apps sign in, save and write through /api/v1 as well: /api/v1/account, /saves, /find, /me/lists, /rides, /walk, /flashcard and the rest. Those take a signed-in session, answer only this site's pages and apps, and are not part of what this page offers — but they keep the same promise: version 1 only ever gains.
