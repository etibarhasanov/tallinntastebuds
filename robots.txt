# Everything on the map is meant to be found.
User-agent: *
Allow: /

# The discount pages are not. Each one is meaningless without a place in the
# query string, and a crawled copy of a code that expires within the hour is
# worse than meaningless. The pages carry a noindex tag of their own too,
# which is the half that actually binds.
Disallow: /deal.html
Disallow: /verify.html
Disallow: /staff.html

# Your own lists, which is a page with nothing on it until somebody signs in.
# It carries a noindex header of its own too.
Disallow: /lists.html

# /list/<id> is deliberately NOT disallowed, and the difference matters.
#
# A shared list has to unfurl — the little preview card in WhatsApp, Telegram
# and a Slack message — and the crawler that builds that card has to fetch the
# page to read its og: tags. A Disallow line here would stop it fetching at
# all, and every list anybody shared would arrive as a bare blue link.
#
# Those pages are still kept out of the index, by the noindex header the
# Function sets on each one: that is a rule about what a crawler may *keep*,
# and it works precisely because the crawler is allowed to read the page
# first. A list is somebody else's writing on this domain and nothing
# moderates it, so it gets to travel and not to be indexed.

# The admin page is not for anybody, crawler or otherwise. Nothing links to
# it and it carries its own noindex tag.
Disallow: /admin.html
